## Motion 作品集网站 - 项目规则与实施指南

### 目标与定位

- **核心目标**: 让招聘方在 30–90 秒内理解风格与能力，并引导至案例详情和联系转化。
- **价值主张**: 真实可验证作品、清晰个人定位、专业过程展示（从 Brief 到 Outcome）。
- **关键转化**: 联系（Email/预约）、下载简历、行业定制落地页访问。

### 用户画像与场景

- **招聘经理/制作人**: 快速判断是否继续看；关注风格、完成度、代表作。
- **技术面试官/导演**: 关注拆解、技术难点与交付规范。
- **HR**: 简洁可信的履历、PDF 下载、联系方式清晰。

### 成功指标（KPI）

- **性能**: 首屏可用 < 2.0s（4G/中端机）、LCP < 2.5s、CLS < 0.1
- **行为**: 首页 → 任一案例详情点击率 ≥ 35%；案例页停留时长中位数 ≥ 90s
- **转化**: 联系/预约/下载简历 ≥ 2–5%
- **增长**: 回访率 ≥ 15%；外部推荐流量周环比 ≥ 10%

### 信息架构（Sitemap）

- `/` 首页：Showreel、精选项目、服务能力、CTA
- `/work` 全部项目：网格+筛选（风格/行业/角色/软件/年份）
- `/work/{slug}` 案例详情：Brief → Process → Outcome → 指标 → 幕后
- `/about` 自我介绍、客户/合作清单、获奖/刊登、设备与软件
- `/contact` 联系方式、社媒、在线预约、微信二维码
- `/resume` 在线简历与 PDF 下载（从 CMS 生成）
- `/press-kit` 头像、品牌素材、One-pager
- `/now` 或 `/log` 可选：创作日志/迭代记录（利于 SEO）

### MVP 功能清单

- **Showreel**: 静音自动播放（可控）、无声提示、Poster 占位
- **项目网格与筛选**: 标签体系（风格/行业/技能/软件/年份）
- **案例详情模板**:
  - Brief/目标与约束
  - 角色与贡献（个人/团队占比）
  - 过程（分镜、风格帧、迭代对比、技术难点）
  - 产出（成片、短切、不同适配版本）
  - 结果与指标（播放量、完播率、投放效果、获奖/刊登）
  - 工具与技术栈（AE/C4D/Houdini/Blender、Lottie、插件）
  - 致谢与版权声明（必要时打码或重制稿）
- **联系与预约**: 表单（含防垃圾）+ 日历预约
- **简历**: 在线页 + PDF 下载（自动从 CMS 生成）
- **SEO 基础**: 语义化结构、OG/Twitter 卡片、站点地图、`schema.org/CreativeWork`
- **分析埋点**: 首页观看、筛选、案例页播放、CTA 点击

### 差异化功能（加分项）

- **交互式 Showreel**: 滚动驱动或分段导航（GSAP ScrollTrigger / CSS Scroll-timeline）
- **分解视图**: 风格帧/分层对比/G-Buffer 通道对比切换
- **行业快速入口**: URL 预筛选（如 `?industry=gaming`）用于投递定制链接
- **自适应视频**: HLS/DASH 多码率；章节导航（chapters）
- **微交互**: Lottie/WebGL 点缀（节制使用）
- **一键导出**: One-pager PDF / Press Kit
- **推荐排序**: 基于来源/行业标签动态排序项目

### 技术选型

- **框架**: Next.js（SSR/SSG/ISR）或 Remix
- **样式**: Tailwind CSS
- **动画**: GSAP + ScrollTrigger、Framer Motion、Lottie
- **视频**: Cloudflare Stream / Mux（HLS、自适应码率、Poster、缩略图）
  - 备选：`ffmpeg` 预转码 H.264 + VP9，720p/1080p
- **媒体优化**: 海报图、预加载首帧、懒加载、`srcset`
- **CMS**: Sanity/Contentful（结构化）或 Notion API（轻量）
- **表单/邮件**: Resend/SendGrid；**预约**: Calendly/Cal.com
- **分析**: Plausible（隐私友好）+ Hotjar（可选，会话回放/热图）
- **部署**: Vercel/Netlify（边缘加速，图片/视频 CDN）
- **可访问性**: 键盘可用、字幕/CC、色彩对比；默认静音自动播放

### 性能与可访问性预算

- **包体**: 首页 ≤ 180KB gzip（不含视频）；第三方依赖最小化
- **图片**: AVIF/WebP；关键图 LQIP/Blur-up 占位
- **动画流畅度**: 目标 ≥ 50fps；避免滚动时布局抖动
- **无障碍**: 视频字幕与文字稿、ARIA 标签、焦点管理

### 数据与埋点事件

- **播放相关**: `event_view_reel`, `event_seek_reel`
- **内容浏览**: `event_click_project`, `event_filter_apply`
- **转化**: `event_submit_contact`, `event_download_resume`, `event_book_meeting`
- **归因**: UTM 追踪来源渠道与岗位 JD 定制链接效果

### 风险与反模式

- **过度动效/3D** 影响可达性与加载
- **自托管单码率视频** 导致卡顿
- **自动播放有声/频繁弹窗** 伤害体验
- **版权/保密风险** 未做处理（打码或重制稿）

### 里程碑计划

- **第 1 周**: 信息架构、视觉基线、CMS 模型；首页 + 1 个完整案例页
- **第 2 周**: 视频播放链路、表单与预约、SEO 与埋点；发布 MVP
- **第 3–4 周**: 差异化交互、更多案例迁移、首页排序 A/B；发布 V2

### 简历可量化表达模板

- 设计并实现 Motion 作品集网站（Next.js + GSAP + Cloudflare Stream），首页 LCP 1.9s，CLS 0.02
- 自建视频转码与自适应播放链路，移动端完播率提升 28%，跳出率下降 17%
- 基于标签与 UTM 的定制化落地页，投递至游戏行业岗位时案例点击率提高 42%
- 建立“分解视图”组件，展示风格帧与合成前后对比，初筛→复试通过率提升至 35%

### 上线前内容清单（Checklist）

- **Showreel**: 30–60s，含章节时间轴
- **案例**: 6–9 个高质量项目，≥3 个含详细过程与指标
- **标签体系**: 行业/风格/技能/年份与封面统一风格
- **素材**: 字幕文件、风格帧导出、分镜稿片段
- **转化**: 简历 PDF、Press Kit、联系方式与预约可用
- **系统页**: 404/500、隐私政策、版权声明
